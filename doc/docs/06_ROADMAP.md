# 06 开发阶段与验收

| 阶段 | 交付 | 退出条件 |
|---|---|---|
| 0 | Android 工程、导航、主题、数据层骨架 | Debug/Release 可构建；主题重启后保持 |
| 1 | JSON 四 Tab | 正确/错误/嵌套/大 JSON 单测；错误行列可定位 |
| 2 | API 请求与响应、历史 | MockWebServer 测试 2xx/4xx/5xx/超时/取消 |
| 3 | BLE + Classic | 真机权限、扫描、连接、断线、收发测试记录 |
| 4 | Wireless/USB ADB + Shell/Logcat | 真实目标设备配对、认证、执行、过滤与断连测试 |
| 5 | 统一会话、导出、稳定性 | 长时间日志无明显卡顿；敏感信息脱敏；回归通过 |

每阶段：先输出设计和变更计划，再写代码、构建、运行单测，最后输出失败项和硬件待验证项。不要用 Demo 假数据替代 P0 的真实功能验收。
