# 02 UI/UX 交互规范（双主题）

## 主题
- 默认：深色专业主题。可选：浅色、跟随系统；设置 > 外观 > 主题模式，选择即时生效并持久化。
- 深色：背景 #0B1220、表面 #172338、主色 #006EFD、主文字 #F2F7FF、次文字 #AAB9D0。
- 浅色：背景 #F5F8FF、表面 #FFFFFF、主色 #006EFD、主文字 #172033、次文字 #52627B。
- 成功 #16A765、警告 #F59E0B、错误 #E5484D。颜色应通过 theme attr 访问，不在业务布局硬编码。
- 适配动态字体、触控区域 >=48dp、横竖屏与系统深色状态栏图标。

## 组件规则
- Material 风格；8dp 网格；页面边距 16dp；卡片圆角 12–16dp；输入/按钮高度建议 >=48dp。
- 主操作按钮强调色，次操作使用描边或弱底色；危险操作红色并二次确认。
- 实时数据：连接/扫描/发送有状态反馈；列表更新避免滚动跳动；日志支持暂停自动滚动。
- 空状态给出原因与下一步；错误显示简明信息与可展开详情。
- 终端采用等宽字体、可复制文本，TX/RX/ERROR 以文字标识而非只依赖颜色。

## 页面清单
1. 启动页：Logo、品牌；不强制等待。
2. 首页：设备状态卡、四模块快捷入口、常用工具、最近会话。
3. 工具箱：JSON、HEX/ASCII、Base64、CRC、时间戳。
4. JSON：格式化/校验/树形/对比 Tab；编辑器行号、错误高亮、复制/压缩/保存。
5. 设备：BLE、Classic、ADB 入口；设备卡与状态。
6. BLE 扫描：扫描进度、过滤、RSSI、连接；服务/特征详情。
7. 蓝牙终端：HEX/UTF-8、收发记录、清空/保存/自动发送。
8. API：方法+URL、Params/Headers/Body/Auth、发送、状态、响应 Tab、历史、环境。
9. ADB：无线/USB/本机、连接详情、Shell、Logcat、系统信息。
10. 记录：按类型/时间筛选、详情、删除、导出。
11. 设置：主题、默认超时、历史清理、隐私与关于。

## 核心交互路径
- JSON：输入 -> 校验 -> 错误定位或格式化 -> 复制/保存。
- BLE：授权 -> 扫描 -> 连接 -> 发现服务 -> 选择特征 -> 读写/订阅 -> 断开。
- API：选环境 -> 编辑请求 -> 发送/取消 -> 查看响应 -> 保存历史。
- ADB：选择方式 -> 授权/配对 -> 连接 -> Shell/Logcat -> 保存/断开。

## 原型使用说明
`assets/mockups/` 为视觉参考，不代表所有按钮已实现；开发时以本规范与 PRD 的交互、可访问性和权限约束为准。
