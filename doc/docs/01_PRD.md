# 01 产品需求文档（PRD）

## 定位
DebugMate 是供 Android 开发者、嵌入式工程师和测试人员使用的移动端综合调试工具，支持多设备、多协议和统一调试会话。

## P0 范围
| 模块 | 需求 | 验收 |
|---|---|---|
| 首页 | 四大模块快捷入口、连接状态、最近会话 | 点击可导航；无数据有空状态 |
| JSON | 粘贴/输入、格式化、压缩、语法校验、行列定位、树形浏览、复制、两份 JSON 对比 | 非法 JSON 显示行列与错误信息；合法 JSON 可格式化和树形展开；数组顺序参与比较 |
| BLE | 扫描、设备列表、连接/断开、服务与特征发现、读/写/通知、HEX/UTF-8 收发 | 真实设备可连接；无权限、超时、断连有提示；按特征属性限制操作 |
| Classic | 已配对设备列表、RFCOMM/SPP 连接、收发、断开 | 明确仅支持兼容 SPP 的设备；不把音频设备当作通用 SPP |
| API | GET/POST/PUT/PATCH/DELETE、URL/Query/Header/Body、请求取消/超时、响应状态/耗时/Headers/Body、历史与环境 | HTTP 错误响应仍展示；网络异常与超时可区分；敏感头默认脱敏 |
| ADB | Wi-Fi 配对/连接、USB OTG 连接、Shell、Logcat、设备信息 | 连接状态准确；命令输出可取消；日志过滤与暂停；失败有可操作提示 |
| 本机信息 | Build/内存/存储/网络等可访问数据 | 不承诺无特权读取全局日志 |
| 通用 | 深色/浅色/跟随系统、会话与历史、导出非敏感日志 | 重启保留主题；历史可清理；导出走系统分享/文件选择器 |

## 不属于 P0
MQTT、完整网络抓包、AI 故障分析、Root/特权日志读取、自动化测试脚本、云同步、复杂协议插件。

## 非功能要求
- 大型日志采用有界缓存，避免 UI 主线程阻塞；列表增量刷新。
- 连接操作可取消，失败可重试；屏幕旋转时状态由 ViewModel 管理。
- 交互反馈明确：加载、成功、失败、无数据、权限拒绝、断开。
- 隐私优先：默认本地存储，导出前脱敏确认。

## 页面与导航
底部 5 Tab：首页 / 工具箱 / 设备 / 终端 / 记录。设置由首页右上角进入。每个核心模块保留返回导航和上下文标题。
